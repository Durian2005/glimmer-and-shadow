# 微光与暗影

一个纯静态的网页版视觉小说（Galgame）。单文件 HTML 驱动，零依赖、零构建、零后端——双击即玩。

> 这是个人的 AI 辅助创作练习作品。剧本、代码与美术素材均由我借助 AI 工具完成，
> 其中全部图片素材由**豆包（Doubao）AI 生成**，详见下方「素材说明」。

## 玩法

在浏览器中打开 `曙光与暗影.html` 即可开始。通过点击推进剧情，遇到分歧点时选择不同分支，剧情走向随之改变。

- **推进剧情**：点击文本区域继续
- **做出选择**：点击选项按钮进入对应分支
- **返回上一节**：点击左上角返回按钮

## 特性

- **单文件架构**：全部样式与逻辑内联于一个 HTML 文件，便于分发与备份
- **分支剧情**：43 个剧情节点，包含旁白、对话、选择与结局四种类型
- **多线回退**：基于栈结构的剧情回溯，可逐级回退至上一节点
- **角色立绘**：6 名角色的立绘按剧情动态显示与切换
- **场景氛围**：7 张背景图配合场景切换

## 故事简介

宁静谷小镇原本是个祥和的地方，直到黑森林中的黑魔法师莫尔根因寻女执念，操控暗影生物封锁了小镇。
17 岁的铁匠学徒利奥怀揣着勇者梦，决定踏上拯救小镇的旅程。

途中他会遇到同行的药师少女艾拉，并在黑森林与暗影洞穴中做出两次关键抉择——
是走幽暗的捷径还是布满藤蔓的古道，是上前劝说莫尔根还是拔剑相向。

## 运行方式

无外部依赖，不需要安装任何东西。

```bash
# 方式一：直接用浏览器打开
start 曙光与暗影.html

# 方式二：本地起一个静态服务器（推荐，避免个别浏览器的本地文件限制）
python -m http.server 8000
# 然后访问 http://localhost:8000
```

## 技术说明

- 纯原生 HTML / CSS / JavaScript，未使用任何框架或第三方库
- 剧情数据集中于 `storyData` 数组，每个节点包含 `type`、`speaker`、`content`、`bgImage`、`showCharacters`、`choices`、`nextIndex` 等字段
- 图片通过相对路径 `images/...` 引用，保持目录结构即可正常加载
- 界面为固定全屏布局，背景图 `background-size: cover`，在桌面浏览器下体验最佳

## 素材说明

本项目的美术素材有明确的来源，特此说明：

- **全部 13 张图片**（7 张场景背景 + 6 张角色立绘）均由**豆包（Doubao）AI 生成**，
  图片右下角带有「豆包AI生成」水印，文件内亦保留原始 AIGC 溯源元数据。
- 生成时使用的场景描述与人物设定属于**提示词工程**的产物，部分原文保留在
  `曙光与暗影.html` 的 `bgDesc` 字段中，可作为 AI 辅助创作的参考样本。
- 剧本、分支结构与全部前端代码由我设计并借助 AI 工具实现。

基于以上情况，本项目的图片素材**不主张独占性著作权**，请勿将其作为原创美术作品转载或二次销售。
如需在其它 AI 创作场景中参考，欢迎自取。
